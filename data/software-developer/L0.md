# Software Developer – Lua Questions & Answers (L0)

Each question is labeled (e.g., `L0-1`) and includes both the original code (possibly with mistakes) and the corrected version.

---

## L0- 1. fixBlipID

### Question

~~~lua
local blip = createBlip(1500, -1500, '3') -- A developer incorrectly used a string instead of a number for the blip ID. Fix it by using a numeric ID.
~~~

### Answer

~~~lua
local blip = createBlip(1500, -1500, 3)
~~~
