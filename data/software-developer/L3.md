## L3- 19. fixEditBoxWidth 

### Question

~~~lua
local editBox = guiCreateEdit(100, 200, "invalidWidth", 30, "Text", false) -- The developer used an invalid width. Use 150.
~~~

### Answer

~~~lua
local editBox = guiCreateEdit(100, 200, 150, 30, "Text", false)
~~~
